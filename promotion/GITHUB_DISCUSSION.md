**Title:** Welcome to the CAUTEL showcase — what to read first

**Body:**

Welcome! This repository is the public face of CAUTEL: a governed autonomy
substrate where agents can only execute, delegate, evolve, and produce
evidence under cryptographic authority. The runtime is proprietary; the
conceptual layer — specs, governance, validation methodology — is public.

**Read in this order:**

1. `README.md` — the three questions every action must answer
2. `docs/THESIS.md` — the case for governed autonomy
3. `governance/CONSTITUTION.md` — the 5-article rule set
4. `governance/FAIL_CLOSED.md` — why refusal is the default
5. `specs/` — the formal object definitions
6. `validation/METHODOLOGY.md` — how we test hostile scenarios

**Good first discussions to have:**

- Which invariants should a governance layer guarantee that the current set
  doesn't cover?
- Federation: what does multi-root delegation look like across organisations?
- Where does fail-closed hurt too much? (Availability tradeoffs)

Feedback, questions, and corrections are welcome. For demos, licensing, or
partnership: see the contact section in the README.
