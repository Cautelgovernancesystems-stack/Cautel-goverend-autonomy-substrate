# Security

CAUTEL is a security product; we treat reports seriously.

## Reporting a vulnerability

Email `security@<your-domain>` with:

1. A description of the issue
2. Steps to reproduce (conceptual or against the public material)
3. Impact assessment
4. Whether you request acknowledgement in the public advisories

We aim to acknowledge within 48 hours and publish a summary advisory after a
fix is available.

## Scope

- In scope: governance invariants, specification gaps that permit
  unauthorised execution, validation methodology flaws, documentation that
  misstates safety properties.
- Out of scope: social engineering, availability of this documentation site,
  issues in third-party dependencies.

## Safe-harbour

Good-faith research conducted without harming other users is always welcome.
